# Cantina-MVP
## O que é  esse projeto?
Este é um projeto feito por Victor, Pietro e Lucas buscando criar um MVP para a cantina do Senai. 
O sistema utiliza o metodo CRUD para o registro e manutenção das mercadorias vendidas.
O banco utilizado foi o mongodb em sua versão atlas, ou seja em sua versão na nuvem.
## Como funciona?
Após selecionar o método que será feito e a requisição for concluida o resultado da mesma é lançado no banco de dados. Para visualizar o resultado de qualquer requisição utilize o metodo get - presente no sistema- e assim você consegue visualizar todos os items de uma vez, ou se deseja visualizar apenas um único item pode busca-lo por via de seu id.
